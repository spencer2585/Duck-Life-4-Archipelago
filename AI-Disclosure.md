# AI usage Disclosure
## TLDR
All code is had written, and feature ideas come from human brains (myself or another player). AI is used to plan updates, explain new concepts, assist in planning complicated features/logic, and identify the cause of descovered bugs

## Full workflow using AI
for those interested ill walk through an example update and how AI is used during the process
Things typically start with a brainstormed list of new features.
When the time comes for an update I identify whats needed most, I typically try to theme an update around something specific.
EX: QOL features, a specific new sanity, or general stability
I then plan out what features make sense to be in that update, plus a list of any bugs that might have not been fixed in any minor versions or hotfixes.
I then feed the planned features list to a chat that is dedicated to assisting me with development of this mod. This chat has been explicitly set up to not generate any code.
The AI then serves a few purposes. I start with a new feature and the AI helps me plan out how to implement a feature.
This specific part typically consists of me laying out a rough outline of what I need to do in code to make this work. The AI then points out any potental flaws or bugs that may arise, and we go back and forth until a a solid plan is in place.
From this point I start actually coding. Depending on how complicated the specific portion of code is I may give what I wrote to the AI to ensure I didnt make any mistakes. Otherwise the AI serves to keep track of what parts are implemented and what parts still need done.
After a new feature or bug fix is implemented I then test it in game, trying out both any intended use and any possible paths where it might break. If issues arise I fix it or if it works as intended I move on to the next thing in the list.
Once an update is complete I run a couple test games with it. First is a small solo game. Second is an async that is typically about a week long async where me and a friend try out the update and any other games I might have ready to test at the time, plus some other friends who are playing other games
So long as the test games go well I then release the update.

When a bug is descovered I try to fix it myself, however bugs can be complicated to identify and fix. If thats the case I will explain the problem to the AI and we collaberate to identify and fix the issue. 
Bug fixing follows the same rules as feature development, no code from AI only pointing out where the issue is.
